
**Repository Overview**

- **Purpose:** This repo collects Power Query work and supporting sales data used for a Sales Overview / Business Intelligence project. It groups reusable query logic, documentation, screenshots, and prepared sales datasets for analysis.

**Contents**

- **Business Power Query:** See [Business_Power_Query](Business_Power_Query/README.md) — contains Power Query transformations, step documentation and a `Screenshots/` folder showing key query steps and outputs. Use these queries to clean and shape raw sales inputs.
- **Sales:** See [Sales](Sales/README.md) — contains the cleaned/exported datasets and short notes about the data structure and common usages for reporting and analysis.

**Quick Start**

- Review the Power Query logic: open [Business_Power_Query](Business_Power_Query/README.md) and the files inside the folder to understand transformation steps.
- Load datasets: open the files in [Sales](Sales/README.md) in Excel, Power BI, or your analysis tool of choice.
- Reuse or adapt queries: copy queries from `Business_Power_Query` into your Power BI or Excel Power Query environment to reproduce the cleaned datasets.

**Files & Links**

**Next Steps / Notes**

- If you add new raw exports, place them in `Sales` and update the `Business_Power_Query` steps if needed.
- Consider versioning large datasets outside the repo (cloud storage) and keeping small sample extracts in `Sales` for reproducible examples.
