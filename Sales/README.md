# Business Intelligence — Sales Overview

A Power BI report that provides an overview of sales performance, trends, and key metrics for the business. The project includes the report exports and supporting documentation to help stakeholders explore revenue, product, and regional performance.

## Features
- Interactive visuals for sales trends, top products, and regional breakdowns
- Filters for date ranges, products, and regions
- Summary KPIs (Total Sales, Orders, Avg. Order Value, YoY Growth)

- `Sales.pdf` — Exported PDF of the report (static snapshot)

## Prerequisites
- Power BI Desktop (latest recommended)
- Access to the report dataset (Excel, CSV, or direct source) if you want to refresh or modify visuals

## How to Open the Report
1. Open Power BI Desktop.
2. If you have a `.pbix` file, choose `File -> Open` and select the file.
3. If you only have the dataset (CSV/Excel), choose `Get data`, load the dataset, and open the `.pbix` report or recreate visuals as needed.
4. Use the filters and slicers in the report to explore trends and metrics.

## Refreshing Data
- If the report is connected to a static file (Excel/CSV), update that file and click `Refresh` in Power BI Desktop.
- If the report uses a live connection or database, ensure credentials and connection strings are up to date before refreshing.

## Notes
- The included `Sales.pdf` is a read-only export. To interactively analyze data, open the report in Power BI Desktop with the `.pbix` file and dataset.
