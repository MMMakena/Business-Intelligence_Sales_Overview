## Project Overview
This project delivers an end-to-end Power BI solution for HR attrition analytics using the IBM HR Analytics Employee Attrition & Performance dataset.

## Problem Statement
The HR department needs to identify key drivers of employee attrition and develop data-driven retention strategies.

## Dataset Description
- **Source:** Kaggle – IBM HR Analytics Employee Attrition & Performance
- **Rows:** 14,999 | **Columns:** 35
- **Key Fields:** Attrition, Department, JobRole, MonthlyIncome, JobSatisfaction, OverTime

## Tools Used
- Power BI Desktop
- Power Query (ETL)
- DAX (measures & calculated columns)

## Steps Followed
1. Data acquisition & understanding
2. Data cleaning & transformation (8 Power Query steps)
3. Star-schema data modeling
4. DAX measures & calculated columns (8 measures + 2 columns)
5. Three-page interactive dashboard
6. Derivation of insights & recommendations
7. GitHub documentation

## Dashboard Features
- **Page 1:** Executive summary (KPIs, trend, slicers)
- **Page 2:** Detailed drill‑down (matrix, decomposition tree, scatter)
- **Page 3:** Performance monitoring (time intelligence, top/bottom N, target gauges)

## Key DAX Measures
- Total Employees, Attrition Count, Attrition Rate, Avg Monthly Income, Avg Job Satisfaction, YTD Attrition, Previous Year Attrition, Dept Attrition %

## Key Insights
1. Early Tenure Employees Drive Majority of Attrition
2. Sales Department Has Critical Retention Crisis
3. Overtime is the Strongest Predictor of Attrition
4. Low Job Satisfaction Strongly Correlates with Leaving
5. Sales Representatives and Laboratory Technicians Are Highest-Risk Roles

## Recommendations
1.  Launch a Sales Department Retention Task Force with Compensation and Workload Reforms
2. Implement a Company-Wide Employee Engagement Initiative Focused on Job Satisfaction and Work-Life Balance
3. Implement a Structured 90-Day Onboarding and Mentorship Program for New Hires

## Challenges Encountered
- Data quality issues (missing values, outliers)
- Complex DAX calculations for time intelligence
- Designing an intuitive dashboard layout
- Ensuring performance optimization with large datasets

## Conclusion
This Power BI solution successfully identifies attrition drivers and provides actionable recommendations, enabling the HR team to reduce turnover and improve employee engagement.
